# JS conventions

- Webpack: `@wpsyntex/polylang-build-scripts` · `npm run dev` / `build:dev` · ESLint: `eslint.config.cjs`
- Shared UI: `@wpsyntex/polylang-react-library` · legacy admin scripts: `js/src/` (`post.js`, `term.js`, `settings.js`, `nav-menu.js`)
- React >= 17, same major as the WordPress bundle
